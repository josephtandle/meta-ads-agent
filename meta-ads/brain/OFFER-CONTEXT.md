# Offer Context Template

## How to use this file

The owner completes this before campaign planning.
Replace bracketed placeholders with approved facts.
Do not include secrets, PII, or unapproved proof.
Use strategy for decisions and this file for offer truth.

## Owner template

* **Offer:** [NAME], [PRICE], [FORMAT], [DELIVERY].
* **Promise:** [ONE SUPPORTABLE OUTCOME]. **Guarantee:** [EXACT TERMS OR NONE].
* **ICP:** [ROLE, CONTEXT, AUTHORITY]. **Fear:** [THEIR WORDS]. **Anti-ICP:** [WHO NOT TO TARGET].
* **Allowed proof:** [CLEARED TESTIMONIALS, DEMOS, FACTS]. **Forbidden claims:** [INCOME, GUARANTEES, PERSONAL ATTRIBUTES, UNSOURCED RESULTS].
* **Assets:** [PAGE, CHECKOUT, APPLICATION, CALENDAR, DEMO, CRM, NURTURE].
* **Funnel:** [AD -> PAGE -> EVENT -> HANDOFF]. **Events:** [PIXEL/CAPI EVENTS]. **SLA:** [OWNER AND RESPONSE TIME].
* **Voice constraints:** [APPROVED TONE, PROHIBITED WORDS, POLICY REQUIREMENTS].

### Target CPA derivation

`maximum CAC [YOUR NUMBER] x close rate [YOUR NUMBER] = maximum cost per attended call [YOUR NUMBER]`

`attended-call ceiling [YOUR NUMBER] x show rate [YOUR NUMBER] = booked-call ceiling [YOUR NUMBER]`

`target CPA [YOUR NUMBER] x fifty / seven = minimum daily learning budget [meta-official]`

Mark unknown values unknown. Do not invent precision.
